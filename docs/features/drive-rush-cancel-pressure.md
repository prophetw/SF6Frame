# 绿冲取消命中与压制计算

## 功能与入口

在 `#/gap-calculator` 选择「绿冲取消 (DRC)」，通过顶部「打中 / 被防御」切换计算类型：被防御时显示中间空隙和最终被防优势；打中时判断能否连招、显示剩余窗口或缺失帧数，以及后续招式普通命中的优势。切换类型保持当前选招与延迟，不退出 DRC 模式。隆提供 `2MK → DRC → 5LP`、`2MK → DRC → 5HP` 两个快捷示例，并列出相同条件下的其他后续招式供比较。

复用项目已有的 Vue、招式名称翻译、角色 JSON、取消合法性检查和 `calculateGap`，不引入新依赖或外部运行时接口。角色数据不由本功能更新。

## 计算规则

数据来源为当前角色 JSON 中的 `Drive Rush Cancel`。该动作的发生帧表示最早可取消进攻击的时间；隆当前为 `9F`，不能用裸绿冲的 `11F` 代替。

- `C`：首招最早绿冲取消位置，沿用原空隙计算器的接触帧口径，首个判定帧为 `1`。
- `D`：绿冲取消发生。
- `L`：用户设置的额外延迟，默认 `0`。
- `S`：后续招式发生。
- `B`：首招防御硬直，优先使用 `raw.blockstun`，缺失时复用原有推导方式 `active + recovery + onBlock`。
- `H`：首招命中硬直，优先使用 `raw.hitstun`，缺失时使用 `active + recovery + onHit`。
- `K`：普通命中为 `0`，打康为 `2`，确反康为 `4`；只作用于首招，打康和确反康互斥。
- `BO`：被防御且对方燃尽（打白）时为 `4`，否则为 `0`。

```text
中间空隙 = C + D + L + S - 1 - (B + BO)
最终被防优势 = 后续招式原始 onBlock + 4（绿冲）+ BO
命中连招窗口 = H + K - (C + D + L + S)
最终命中优势 = 后续招式原始 onHit + 4（绿冲）
```

绿冲的 `+4F` 加在后续普通技命中或被防后的硬直差上，不加到首招的硬直中。燃尽则分别延长两次防御硬直：缩小中间空隙，并提高最终被防优势；不增加命中硬直或命中优势。打康/确反康增加首招的命中硬直，连招中的后续招式按普通命中计算，避免重复叠加康加成。

打中时显示「普通命中」「打康（+2F）」「确反康（+4F）」互斥选项，被防御时显示「打白（对方燃尽，被防 +4F）」复选项。切换类型时保留各自选项，仅启用当前类型适用的加成；切换角色或点击快捷示例会重置选项及额外延迟。

首招数据的 `notes` 若标明绿冲取消延迟，自动使用对应位置：`after active frames` 取持续帧末尾；指定第 N 个持续帧则取 N；指定第 N 个恢复帧则取持续帧数 + N。隆 `2MK` 持续 `3F`，并注明持续帧结束后才可绿冲取消，因此 `C = 3`。

所有计算假定首个判定帧接触；被防御模式假定两招均能成功防御，命中模式检验首招命中后能否接上后续招式。不模拟距离、命中框、推离或打点造成的变化。首招不支持多段/条件持续帧；涉及命中段、范围或无法识别的取消时机也显示不支持。后续招式限地面普通技和指令普通技，不将必杀技或投技视为获得 `+4F` 的攻击。命中优势为 `KD` 等非数字或缺少当前计算类型对应的有效硬直数据时，显示不支持计算，不按零帧处理。

选招与对比表排除 `5MP~LK`、`5HP~HK` 等含 `~` 或 `>` 的目标连段/架势派生输入。这些条目的发生帧属于需要前置动作的后续段，不能直接作为绿冲后的独立普通技计算。

## 空隙口径

沿用页面说明的「帧数表黑格」口径：

- `Gap < 0`：攻击仍落在防御硬直内，为连防。
- `Gap = 0`：没有黑格，但接触帧是对方首个可动帧，仍可启动无敌技。
- `Gap = 1~2`：4F 普通技来不及生效，无敌技可插入。
- `Gap = 3`：4F 普通技同帧生效，可能相杀。
- `Gap >= 4`：4F 普通技可先于后续招式生效。

后三类仍受距离和判定影响。新模式单独处理这些边界，原 Link/Cancel 模式保持已有行为。

命中模式复用原计算器的连招窗口口径：窗口 `>= 0` 表示可以连上（`0F` 为刚好接上）；窗口 `< 0` 表示连招失败，主结果显示缺失帧数，对比表保留带符号的窗口。

## 隆的计算示例

依据仓库 `ryu.json`（`lastUpdated: 2026-03-25`），双方未燃尽、额外延迟为 0：

| 压制 | 中间空隙 | 判定 | 最终被防优势 |
| --- | --- | --- | --- |
| 2MK → DRC → 5LP | `3 + 9 + 4 - 1 - 16 = -1F` | 连防 | `-1 + 4 = +3F` |
| 2MK → DRC → 5HP | `3 + 9 + 10 - 1 - 16 = 5F` | 4F 普通技可抢动 | `-2 + 4 = +2F` |

命中时 `2MK` 原始命中硬直为 `23F`，同样按最速衔接：

| 连招 | 普通命中窗口 | 打康窗口 | 确反康窗口 | 后续普通命中优势 |
| --- | --- | --- | --- | --- |
| 2MK → DRC → 5LP | `+7F` | `+9F` | `+11F` | `+8F` |
| 2MK → DRC → 5HP | `+1F` | `+3F` | `+5F` | `+8F` |

以上为当前本地数据的计算结果，不代表已经在最新游戏版本训练场复核。
